# 🚨 SOC Investigation Lab – Smart Cybersecurity Assistant

This project demonstrates a full **SOC (Security Operations Center) simulation environment** combined with a **Smart AI-powered Cybersecurity Assistant**.

It covers the complete lifecycle from **attack simulation → log collection → detection → response → AI-assisted analysis**.

---

## 🧩 Project Overview

The lab includes:

- 🔴 Attacker Machine (Kali Linux)
- 🟡 Victim Machine (Windows + Sysmon + Splunk UF)
- 🟢 SIEM (Splunk Enterprise)
- 🔵 SOC Analyst Response Workflow
- 🤖 Smart Cybersecurity Assistant (LLM-based)

## 🔍 Features

### 🛡 SOC Lab
- Attack simulation (Recon → Persistence)
- Log collection using Sysmon & Splunk
- Detection via correlation rules
- Alerts & dashboards

### 🤖 AI Assistant
- Threat Analyzer → Risk scoring & IoCs
- Log Analyzer → Anomaly detection
- Password Checker → Strength analysis

---

## ⚙️ Technologies Used

- Splunk Enterprise (SIEM)
- Kali Linux
- Windows 10 + Sysmon
- Streamlit (Frontend UI)
- Python
- Prompt Engineering
- Gemini API (LLM)
